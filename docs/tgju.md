# داده‌های عمومی TGJU

این قابلیت برای تحلیل قیمت‌های عمومی TGJU است. داده‌ها از نقاط دسترسی عمومی و بدون احراز هویتِ مورد استفادهٔ وب‌سایت دریافت می‌شوند و به اشتراک یا توکن Persian API نیاز ندارند. عمومی بودن دسترسی فنی به معنی اعطای مجوز استفاده از داده نیست. `fima` وابسته به TGJU نیست و ادعای تأیید، همکاری یا مجوز رسمی آن را ندارد. مسئولیت رعایت [شرایط ارائه‌دهنده](https://www.tgju.org/terms) و محدودیت‌های مربوط بر عهدهٔ کاربر است. دسترسی و ساختار منبع ممکن است تغییر کند.

## کشف گروه‌ها و نمادها

```python
from fima import get_tgju_categories, get_tgju_instruments

categories = get_tgju_categories()
currencies = get_tgju_instruments("ارز")
matches = get_tgju_instruments("طلا", search="عیار")
```

`get_tgju_categories()` پارامتری ندارد و جدولی با ستون‌های `Category`، `Market` و `EnglishName` برمی‌گرداند. نام گروه‌ها و مسیر جستجوی آن‌ها از پیکربندی ساختاریافتهٔ صفحهٔ اصلی کشف می‌شود؛ این پیکربندی ده دقیقه در حافظه نگه‌داری می‌شود. فهرست نمادها به‌صورت دستی در بسته ثبت نشده است.

گروه‌های این نسخه: طلا و نقرهٔ داخلی، سکه، ارز داخلی، ارز دیجیتال، فلزات گرانبها، فلزات پایه، انرژی، کالا، بازارهای ارزی و شاخص‌های جهانی بورس. نام فارسی فعلی هر گروه را از جدول ببینید. نام‌های انگلیسی پایدار `gold`، `coin`، `currency`، `crypto`، `precious_metals`، `base_metals`، `energy`، `commodity`، `forex` و `indices` نیز پذیرفته می‌شوند. پوشش گروه به معنی وجود قیمت یا تاریخچه برای تک‌تک نمادهای آن نیست.

```python
instruments = get_tgju_instruments(category=None, search=None, page=1)
```

`category` نام گروه است؛ `None` یک صفحه از هر دو بازار داخلی و جهانی را ترکیب می‌کند. `search` جستجوی سمت منبع با نام یا نماد است. `page` عدد صحیح مثبت و از یک شروع می‌شود. تعداد ردیف هر صفحه را TGJU تعیین می‌کند؛ در بررسی فعلی معمولاً ۱۵ ردیف برای هر بازار بود. `attrs["page"]` صفحهٔ درخواستی و `attrs["has_more"]` وجود صفحهٔ بعد را نشان می‌دهد. یک صفحه ممکن است پس از کنار گذاشتن خانواده‌های خارج از پوشش خالی باشد ولی همچنان ادامه داشته باشد؛ برای تشخیص پایان از تعداد ردیف‌ها استفاده نکنید. دریافت همهٔ ده‌ها هزار ابزار در یک فراخوانی انجام نمی‌شود.

برای دریافت صفحه‌های بیشتر، بدون درخواست موازی و تنها به میزان نیاز ادامه دهید:

```python
page = 1
while True:
    instruments = get_tgju_instruments("ارز", page=page)
    print(instruments)
    if not instruments.attrs["has_more"]:
        break
    page += 1
```

| ستون فهرست | معنی |
|---|---|
| `Symbol` | نام متنی قابل استفاده در سایر توابع؛ شناسهٔ عددی نیست |
| `InstrumentName`, `EnglishName` | نام فارسی و انگلیسی اعلامی منبع |
| `Category` | زیرگروه اعلامی نماد، مانند ارز آزاد یا سکه نقدی |
| `Group` | نام انگلیسی خانوادهٔ داده، مانند `currency` |
| `Market` | بازار داخلی یا جهانی |
| `Currency` | کد پول اعلامی فهرست با حروف بزرگ، مانند `IRR` یا `USD`؛ بدون تبدیل |

`Category` زیرگروه نماد است، در حالی که آرگومان `category` نام خانواده از `get_tgju_categories()` است. برای انتخاب دقیق‌تر یک زیرگروه، ردیف مطلوب را در فهرست پیدا کرده و `Symbol` آن را استفاده کنید.

## نمای آخرین داده‌های بازار

```python
from fima import get_tgju_market

fx = get_tgju_market("ارز")
gold = get_tgju_market("gold", page=1)
bitcoin = get_tgju_market("crypto", search="بیت کوین")
```

امضای تابع `get_tgju_market(category=None, *, search=None, page=1)` و معنای پارامترها مانند فهرست نمادها است. خروجی همان ستون‌های فهرست و ستون‌های زیر را دارد. جستجو، درخواست انتخاب یکتای یک نماد نیست و می‌تواند چند نتیجه برگرداند.

| ستون | معنی |
|---|---|
| `Price` | آخرین قیمت اعلامی ویجت |
| `OpeningPrice`, `HighPrice`, `LowPrice` | بازگشایی، بیشترین و کمترین مقدار اعلامی |
| `PriceChange`, `PercentageChange` | تغییر و درصد تغییر با علامت؛ درصد به واحد درصد، نه نسبت |
| `ChangeDirection` | جهت خام منبع: `high`، `low` یا رشتهٔ خالی |
| `UpdateLabel` | متن زمان یا تاریخ کوتاه منبع با ارقام لاتین |
| `UpdateTime` | `HH:MM:SS` only when the provider supplies a clock time; otherwise missing |
| `UpdatedAt` | زمان به‌روزرسانی منبع؛ منطقهٔ زمانی ساخته نمی‌شود |
| `Unit` | در منبع ویجت اعلام نشده و خالی است؛ برای واحد حجمی، مشخصات نماد را بگیرید |
| `HasSnapshot` | آیا منبع ویجت برای ردیف داده‌ای برگرداند؟ |

نبود یک نماد در پاسخ ویجت به حذف آن از جدول منجر نمی‌شود: `HasSnapshot=False` و قیمت‌ها خالی خواهند بود. این ستون نشانگر باز یا بسته بودن بازار نیست. صفر با دادهٔ مفقود تفاوت دارد. قیمت قبلی، قیمت پایانی روز جاری یا وضعیت باز/بسته وقتی منبع اعلام نکرده باشد محاسبه یا حدس زده نمی‌شود. `UpdatedAt` را بررسی کنید؛ آخرین مقدار موجود ممکن است قدیمی باشد.

## انتخاب نماد و مشخصات

```python
from fima import get_tgju_instrument_details

dollar = get_tgju_instrument_details("دلار", "ارز")
gold18 = get_tgju_instrument_details("طلای 18 عیار / 750", "طلا")
bitcoin = get_tgju_instrument_details("Bitcoin", "crypto")
print(bitcoin["Unit"])
```

امضای تابع `get_tgju_instrument_details(instrument, category=None)` است. `instrument` نام فارسی، نام انگلیسی یا `Symbol` فهرست است. ارقام فارسی/عربی، تفاوت «ی/ي» و «ک/ك»، فاصله‌ها، نیم‌فاصله و بزرگی حروف انگلیسی در مقایسه یکسان می‌شوند. همهٔ صفحات نتایج جستجوی منبع بررسی می‌شوند؛ تطابق دقیق بر تطابق جزئی اولویت دارد. چند تطابق با شناسه‌های متمایز، `ValueError` همراه با گزینه‌ها ایجاد می‌کند. گزینهٔ نخست به‌صورت خودکار انتخاب نمی‌شود. برای کاهش درخواست‌ها گروه را مشخص کنید و در ابهام از `Symbol` فهرست استفاده کنید.

اگر جستجوی نماد تطابقی نداشته باشد، جداکننده‌های `_` و `-` برای یک جستجوی دیگر به فاصله تبدیل می‌شوند؛ انتخاب نهایی همچنان با نام یا نماد اصلی مقایسه می‌شود. برای نمونه، TGJU هنگام بررسی `commodity_canola_oil` را به صورت کامل پیدا نمی‌کرد ولی جستجوی کلمه‌ها همان نماد را برمی‌گرداند.

خروجی `dict` شامل ستون‌های فهرست، `ProfileName`، `CurrencyName`، `Unit`، `Country` و `ProfileURL` است. `CurrencyName` نام پول در پروفایل و `Unit` واحد حجمی آن است. `ProviderMetadata` برچسب‌ها و مقادیر پروفایل و `ProviderInstrument` شیء فهرست را برای بررسی منشأ نگه می‌دارند؛ این دو قرارداد ثابتِ ستونی ندارند. واحد یا کشور اعلام‌نشده `None` است؛ برچسب خالی اصلی در `ProviderMetadata` باقی می‌ماند. هنگام بررسی، واحد حجمی بیت کوین در پروفایل خالی بود؛ `fima` آن را «سکه»، «واحد» یا مقدار دیگری فرض نمی‌کند.

## تاریخچهٔ روزانه

```python
from fima import get_tgju_history

usd = get_tgju_history("دلار", "ارز")
gold18 = get_tgju_history(
    "طلای 18 عیار / 750", "طلا",
    start_date="1405/07/01", end_date="1405/07/23", jalali=True,
)
brent = get_tgju_history("نفت برنت", "انرژی", start_date="2026-10-01")
print(usd.attrs)
```

امضای تابع:

```text
get_tgju_history(
    instrument, category=None, *, start_date=None, end_date=None, jalali=False,
)
```

انتخاب نماد مانند تابع مشخصات است. حدود تاریخ شامل ابتدا و انتها هستند. تاریخ رشته‌ای به شکل `YYYY-MM-DD` یا `YYYY/MM/DD` و ارقام فارسی/لاتین پذیرفته می‌شود؛ در حالت میلادی `datetime.date` و در حالت شمسی `jdatetime.date` نیز قابل استفاده‌اند. `jalali` باید بولی باشد و فقط تقویم **ورودی** را تعیین می‌کند. حدود میلادی به شمسی مورد انتظار TGJU تبدیل می‌شوند. بدون حدود، همهٔ تاریخچهٔ موجود در منبع دریافت می‌شود؛ مدت پوشش هر نماد متفاوت است.

| ستون تاریخچه | نوع و معنی |
|---|---|
| `GregorianDate` | pandas `datetime64[ns]`; missing dates are `NaT` |
| `JalaliDate` | ASCII `YYYY-MM-DD` strings; missing dates are `pd.NA` |
| `OpeningPrice`, `LowPrice`, `HighPrice`, `ClosingPrice` | بازگشایی، کمینه، بیشینه و پایانی روزانه |
| `PriceChange`, `PercentageChange` | تغییر و درصد تغییر اعلامی منبع، با جهت آن |
| `ChangeDirection` | جهت خام تغییر |

دو تاریخ منبع جداگانه خوانده می‌شوند؛ یکی از دیگری ساخته نمی‌شود. داده به ترتیب صعودی `GregorianDate` برمی‌گردد. فقط تکرارهای کاملاً یکسان پس از نرمال‌سازی حذف می‌شوند؛ ردیف‌های هم‌تاریخِ متناقض حفظ می‌شوند. تاریخ یا قیمت خالی ساخته یا با مقدار روز دیگر پر نمی‌شود. پاسخ معتبر و خالی، جدول خالی با همین ستون‌ها دارد.

در `attrs`، فیلدهای `Symbol`، `InstrumentName`، `Currency`، `CurrencyName`، `Unit`، `ProfileURL` و `SourceURL` منشأ و واحد داده را مشخص می‌کنند. تبدیل ریال/تومان، تبدیل ارز، تعدیل قیمت، ساخت روزهای تعطیل یا محاسبهٔ مجدد تغییرات انجام نمی‌شود. مقادیر صحیح بدون گذر از اعشار خوانده می‌شوند؛ اعداد اعشاری با نوع عددی معمول پایتون/pandas نمایش داده می‌شوند.

## منابع انتخاب‌شده و موجودی داده

بررسی در ۲۵ مهر ۱۴۰۵ برابر ۲۰۲۶/۱۰/۱۷ انجام شد. از API اشتراکی استفاده نشده و هیچ کد شخص ثالثی کپی نشده است.

| داده | منبع و دلیل انتخاب | پوشش و تناوب |
|---|---|---|
| گروه‌ها | پیکربندی ساختاریافتهٔ جستجو در صفحهٔ اصلی | خانواده‌های بالا؛ فهرست نام‌ها، نه قیمت؛ حافظهٔ ده‌دقیقه‌ای |
| نمادها | `https://api.tgju.org/v1/newsearch` | جستجوی صفحه‌بندی‌شدهٔ همان سایت؛ نام، نام انگلیسی، نماد، زیرگروه و کد پول |
| آخرین قیمت‌ها | `https://api.tgju.org/v1/widget/tmp` | JSON ویجت با گروه‌های حداکثر ۲۰ نماد؛ مقدار و زمان اعلامی؛ بدون تضمین تازگی |
| تاریخچه | `https://api.tgju.org/v1/market/indicator/summary-table-data/{symbol}` | جدول روزانهٔ JSON با سلول‌های تغییر به شکل HTML؛ شمار ردیف و صفحه‌بندی |
| مشخصات | `https://www.tgju.org/profile/{symbol}` | برچسب‌های مشخصات در HTML؛ در منابع JSON منتخب واحد حجمی وجود نداشت |

طلا و سکه و ارز داخلی معمولاً قیمت‌های داخلی را دارند؛ فلزات، انرژی، کالا، رمزارز و شاخص‌های جهانی ممکن است پول‌ها و واحدهای متفاوت داشته باشند. واحد هر سری را از مشخصات خودش بخوانید؛ `Currency` فهرست و `CurrencyName` پروفایل از دو بخش منبع آمده‌اند و اگر ناسازگار باشند به‌صورت خودکار یکسان‌سازی نمی‌شوند. تناوب تقویمی تاریخچه روزانه است؛ تناوب به‌روزرسانی قیمت لحظه‌ای را منبع تعیین می‌کند و تضمینی در کتابخانه ندارد.

مسیریاب عمومی `v1/market/finder/list` نیز بررسی شد: یک درخت کشف است و بعضی شاخه‌ها ده‌ها هزار نماد دارند. جستجوی صفحه‌بندی‌شده برای استفادهٔ عادی درخواست و دادهٔ کمتری نیاز دارد. `v1/market/list-data` برای دستهٔ والد می‌تواند خالی باشد. جریان عمومی `call2.tgju.org/ajax.json` بعضی نمادهای قدیمی و قیمت‌هایی با زمان متفاوت داشت؛ به جای ترکیب بی‌صدای آن با ویجت، یک منبع مشخص برای نمای بازار انتخاب شد.

## ناسازگاری‌ها و محدودیت‌های ارائه‌دهنده

- در بررسی دلار، تغییر ترتیب سرور از نزولی به صعودی، ستون‌های تغییر/درصد را برای یک تاریخ جابه‌جا می‌کرد؛ برای نمونه ردیف ۲۰۲۶/۱۰/۱۲ با ترتیب صعودی تغییر `48900` و با ترتیب نزولی تغییر `17050` داشت، در حالی که قیمت‌های OHLC ثابت بودند. تاریخچه همیشه با ترتیب نزولی از منبع گرفته و سپس فقط ترتیب ردیف‌ها در خروجی صعودی می‌شود. تغییرها از OHLC دوباره محاسبه نمی‌شوند.
- صفحه، ویجت و جریان قیمت ممکن است زمان‌های به‌روزرسانی متفاوت یا دادهٔ ذخیره‌شدهٔ قدیمی داشته باشند. مقایسهٔ قیمت‌ها بدون تطبیق زمان به معنی خطای کتابخانه نیست. مقادیر مشکوک ارائه‌دهنده اصلاح نمی‌شوند.
- در تاریخچهٔ برنتِ ۲۰۲۶/۱۰/۰۸، سایت و JSON هر دو `Low=100.2`، `High=99.556` و `Close=103.356` داشتند. این ناسازگاریِ حدود قیمت بدون جابه‌جایی یا اصلاح حفظ می‌شود. بررسی ستون‌های تغییر و حدود OHLC در [مسئلهٔ ۴۹](https://github.com/hemoboghosian/fima/issues/49) پیگیری می‌شود.
- فقدان واحد حجمی بیت کوین، تفاوت مدت تاریخچهٔ نمادها و نبود داده برای بعضی ورودی‌های فهرست محدودیت منبع هستند. وجود یک نماد در فهرست تضمین دسترسی تاریخچه یا آخرین قیمت آن نیست.
- این نسخه خبر، تبلیغ، پیش‌بینی، اندیکاتور محاسباتی، دادهٔ لحظه‌ای درون‌روزی، شاخه‌های خرده‌فروشی یا داده‌هایی که به منبع مستقل/احراز هویت نیاز دارند را جمع‌آوری نمی‌کند. شاخص‌های این قابلیت، گروه جهانی TGJU هستند؛ برای دادهٔ بازار سرمایهٔ ایران از قابلیت‌های مربوط بسته استفاده کنید.

## خطاها و رفتار شبکه

نام ناشناخته/مبهم، ورودی تاریخ یا صفحهٔ نامعتبر، JSON/ساختار/عدد/تاریخ نامعتبر و صفحه‌بندی تکراری، ناقص یا متغیر با `ValueError` گزارش می‌شوند. خطاهای اتصال و گواهی از خانوادهٔ `requests.RequestException`، خطای مهلت `requests.Timeout` و خطای وضعیت HTTP به شکل `requests.HTTPError` منتشر می‌شوند. پاسخ نامعتبر به جدول خالی تبدیل نمی‌شود.

مهلت اتصال ۱۰ و خواندن ۳۰ ثانیه است. اتصال‌ها در هر فراخوانی بازاستفاده و در پایان بسته می‌شوند. بین درخواست‌های این ماژول در یک پردازش حداقل نیم‌ثانیه فاصله وجود دارد. فقط برای `500`، `502`، `503` و `504` یک بار دیگر تلاش می‌شود. برای `401`، `403` یا `429` تلاش مجدد یا تغییر دامنه برای دور زدن محدودیت انجام نمی‌شود. بررسی گواهی TLS فعال می‌ماند. صفحه‌بندی خودکار جستجوی انتخاب نماد و تاریخچه حداکثر ۲۰۰ صفحه دارد و عبور از سقف خطا ایجاد می‌کند؛ بازه یا گروه را محدود کنید. واردسازی ماژول شبکه را فراخوانی نمی‌کند.

اگر ارائه‌دهنده احراز هویت، CAPTCHA یا مسدودسازی اعمال کند، دسترسی دور زده نمی‌شود. توکن خصوصی، نشست کاربر یا روش عبور از محدودیت در این قابلیت وجود ندارد.
